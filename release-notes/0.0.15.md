## What's new in v0.0.15

**Homebrew Cask install + Sparkle 2 auto-updates**

    brew install --cask chiliec/tap/claudebar

No more `curl | xattr` ritual. The cask strips the Gatekeeper quarantine flag automatically on install, and Sparkle handles update prompts inside the app.

**Fixes since v0.0.14 (which was unlaunchable, now retracted)**
- Bundle `Sparkle.framework` inside the .app and sign its internal XPC services + Updater.app
- Apply entitlements during signing
- Cask `postflight` block strips quarantine so first launch works without the Gatekeeper popup

**Manual install (no Homebrew)**

Download the `.zip` below, unzip, drag `ClaudeBar.app` to `/Applications`. You'll see a one-time Gatekeeper prompt — right-click → Open to bypass it.
