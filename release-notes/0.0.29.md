### The app now launches for everyone

Builds through 0.0.28 were missing a bundle type declaration, so macOS did not
recognize ClaudeBar as an application and quietly refused to launch it whenever
the copy carried a quarantine flag — which is every copy downloaded from the
releases page. Nothing appeared, and because ClaudeBar has no Dock icon or
window, there was nothing to indicate why. Fixed.

Builds are also universal again: 0.0.28 shipped Apple Silicon only and could
not run on Intel Macs at all.

If a previous download never started for you, replace it with this build —
a copy that never launched could not update itself.
