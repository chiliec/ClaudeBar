## What's new in v0.0.18

**7-Day windows now track the live API**

The popover's 7-Day section used to hard-code Sonnet/Opus/Design rows. When Claude.ai stopped reporting those windows, they showed a misleading **0%** instead of disappearing.

- Per-model windows now render **only when the API actually reports them** — a missing window means "not provisioned", so the row is hidden rather than shown as empty.
- Any new window Claude.ai returns is surfaced automatically (no app update needed), including codenamed credit pools like `amber_ladder`, shown with their dollar balance (e.g. **$0 / $2,500**).
- Known windows keep friendly names (Sonnet, Opus, Design); unrecognized codenames are humanized (`amber_ladder` → "Amber Ladder").
