## What's new in v0.0.17

**Cask renamed: `claudebar-menubar`**

    brew install --cask chiliec/tap/claudebar-menubar

The short name `claudebar` in the central Homebrew tap belongs to an unrelated project. Using a unique short name avoids `brew upgrade` silently replacing your install with the wrong app.

If you installed an earlier `chiliec/tap/claudebar`, uninstall it first:

    brew uninstall --cask claudebar --force
    brew install --cask chiliec/tap/claudebar-menubar
