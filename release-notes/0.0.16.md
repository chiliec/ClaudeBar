## What's new in v0.0.16

**Homebrew Cask install + in-app Sparkle 2 updates**

    brew install --cask chiliec/tap/claudebar

First launch needs no manual `xattr` or right-click bypass — the cask strips quarantine on install, and updates ship via Sparkle inside the app.

**Fixes since v0.0.15 (retracted: dyld couldn't find bundled Sparkle.framework)**
- Inject `@executable_path/../Frameworks` rpath so the binary finds bundled Sparkle.framework at runtime

**Manual install (no Homebrew)**

Download the `.zip` below, unzip, drag `ClaudeBar.app` to `/Applications`. You'll see a one-time Gatekeeper prompt — right-click → Open to bypass it.
