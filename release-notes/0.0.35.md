### Fixes an empty menu bar at launch

If macOS asked for your keychain password when ClaudeBar started, the app froze
before it had drawn anything — no icon in the menu bar, nothing to click, until
the prompt was answered. macOS asks whenever the saved credentials were written
by an older, differently signed copy of ClaudeBar, so this hit anyone upgrading
from a build before 0.0.29.

ClaudeBar now reads your saved credentials in the background. The menu bar icon
appears immediately, and a password prompt no longer takes the app with it.
