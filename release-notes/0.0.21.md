## What's new in v0.0.21

**Per-model weekly limits keep working after the API change**

Claude.ai moved the per-model weekly limit out of the old `seven_day_*` windows (now empty) and into a new structure that names the model directly — currently "Fable". ClaudeBar now reads that format, so the model's weekly usage reappears in the 7-Day Windows section, labeled with the exact model name the API reports and future-proof against further model renames.
