### Fixes the crash while signing in on macOS 26

ClaudeBar drew its buttons with the new Liquid Glass styles. Resolving a glass
effect inside ClaudeBar's panel crashes the app on macOS 26, and the "Sign in
with Claude" button used one — so a new install could crash partway through
authorizing, before it ever showed any usage.

0.0.31 removed one glass effect, on the subscription tier badge, but missed the
three button styles that reach the same code. All Liquid Glass is now gone from
the app, on every macOS version, and a test fails the build if any of it comes
back.
