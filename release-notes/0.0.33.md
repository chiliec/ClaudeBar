### Fixes the crash at the end of signing in

Approving access in the browser sent you back to ClaudeBar, which then crashed
before it could save anything — so signing in could never complete, and the app
returned to its setup screen every time.

The panel's translucent background was drawn by an AppKit view embedded in the
SwiftUI layout. Positioning it ran the auto layout engine on every frame from
inside the layout pass, and the moment the panel changed height — which is what
finishing sign-in does, swapping the short setup view for the tall usage view —
that ran the main thread out of stack.

The background is now drawn behind the interface rather than inside it, so it is
positioned once instead of on every frame.
