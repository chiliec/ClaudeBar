## What's new in v0.0.14

**New install path: Homebrew Cask**

    brew install --cask chiliec/tap/claudebar

No more `curl | xattr` ritual. First launch shows the standard macOS Gatekeeper prompt — click **Open** once and you're done.

**In-app auto-updates via Sparkle 2**

The app now checks for updates on its own and shows a native "Update available" dialog when a new version ships. Brew is install-only; Sparkle owns the update lifecycle.

**Under the hood**
- Replaced the custom `UpdateChecker` with Sparkle 2.x
- New `appcast.xml` feed served from this repo
- EdDSA-signed update zips for tamper protection
- Single-command release pipeline (`scripts/release.sh`)

**Manual install (no Homebrew)**

Download the `.zip` below, unzip, drag `ClaudeBar.app` to `/Applications`. Same Gatekeeper prompt on first launch.
