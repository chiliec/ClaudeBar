### Fixes a crash on launch that affected every machine but the developer's

ClaudeBar shipped without the bundle holding its interface text. Every label in
the app is loaded from it, so the app trapped and quit the instant it drew
anything — no menu bar icon, no window, no error. On the machine the releases
were built from it kept working, because older build tooling wrote an absolute
path to the build directory into the binary as a fallback, and that directory
was right there. Nobody else had it.

0.0.29's packaging fixes were real but could not help on their own: the app got
past Gatekeeper and then crashed a moment later. Releases are now smoke tested
by launching the built app from outside the build directory and requiring it to
survive, which is the check that would have caught this.
