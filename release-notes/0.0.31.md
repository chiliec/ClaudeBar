### Fixes a crash when opening the panel on macOS 26

The subscription tier badge next to your organisation's name was drawn with the
new Liquid Glass effect. Resolving that effect inside ClaudeBar's panel crashed
the app outright on macOS 26. It only ever happened once signed in, since that
is when the badge first appears — so a fresh install looked fine and then died
the moment it had something to show.

The badge is now a plain capsule on every macOS version. At that size it looks
much the same.
